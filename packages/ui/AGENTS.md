# `@v-monorepo/ui`

Import by path (`@v-monorepo/ui/components/button`). Import `globals.css` once in the app entry. Mount `<Toaster />` once in the app shell. `cn` comes from `@v-monorepo/utils`.

shadcn lives here (`components.json`). Run the CLI with `-c packages/ui` from the repo root.
