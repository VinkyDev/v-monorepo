# `@v-monorepo/utils`

Local helpers. Import from `@v-monorepo/utils`. Prefer [es-toolkit](https://es-toolkit.dev) (`import { … } from "es-toolkit"`); add a helper here when none exists.

`waitUntil` polls a predicate until it passes or the deadline hits. One-shot waits stay on es-toolkit `delay` / `withTimeout`.

Docs: [llms.txt](https://es-toolkit.dev/llms.txt), then the matching page; [llms-full.txt](https://es-toolkit.dev/llms-full.txt) when the name is unknown.
